#  About Me:
Sou licenciado em Comunicação e Multimédia pela UTAD e recentemente concluí o meu estágio curricular na área de programação, onde tive a oportunidade de integrar uma equipa real e aplicar boas práticas de engenharia de software e metodologias ágeis.
Tenho um interesse muito forte pelo desenvolvimento backend com PHP e Laravel, mantendo também bases sólidas para trabalhar o lado frontend com HTML, CSS e JavaScript. No meu percurso académico, profissional e pessoal, tenho focado o meu desenvolvimento na criação de websites, aplicações e APIs robustas, aliando a lógica estrutural a uma preocupação constante com a segurança na camada de aplicação e a proteção de dados.
